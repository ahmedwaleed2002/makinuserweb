# Makin User Website (JSX Version)

This project is a JSX-based version of the Makin User Website. It includes a range of features to provide a rich user experience for managing heavy machinery rentals. 

## Key Features

- **Responsive UI**: Built using Tailwind CSS to ensure responsiveness across devices.
- **Booking Management**: Features a booking form to capture rental information.
- **Interactive Map**: Mock map component for displaying equipment locations.
- **User Authentication**: Context-based login and logout functionality.
- **Styled Components**: Utilizes JSX components for Button, Input, etc.

## Installation

1. **Clone the repository**:
   ```
   git clone https://github.com/yourusername/makin-user-website-jsx.git
   ```

2. **Navigate to the project directory**:
   ```
   cd makin-user-website-jsx
   ```

3. **Install dependencies**:
   ```
   npm install
   ```

## Running the Development Server

Start the development server:
```
npm run dev
```

The application will be available at `http://localhost:5173/`.

## Building for Production

To create a production build, use:
```
npm run build
```

## Important Files

- `src/components`: Contains all the JSX component files.
- `src/context`: Handles state management with React Context.
- `src/pages`: Page components for different routes.
- `tailwind.config.js`: Configuration for Tailwind CSS.
- `postcss.config.js`: PostCSS setup for Tailwind.
